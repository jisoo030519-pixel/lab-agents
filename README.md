# AI 기반 연구실 업무 자동화 플랫폼

인천대 연구실의 반복 업무를 5개 AI Agent로 자동화한다.
각 Agent는 독립적으로 동작하되, `shared/` 를 통해 서로의 데이터를 읽는다.

```
                    AI Research Lab Platform
                              │
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
   회계·급여              GitLab 관리            일정 관리
     (1)                    (2)                   (4)
        │                     │                     │
        └──────────────┬──────┴──────────┬──────────┘
                       │                 │
                 세미나 Knowledge    코드 인수인계
                     (3)                (5)
                       │                 │
                       └────────┬────────┘
                                │
                          shared/  (공유 DB)
```

## 5개 Agent

| # | Agent | 핵심 역할 | 상태 |
|---|---|---|---|
| 1 | [회계·급여](agents/1-finance) | 월급, 인건비, 참여율 관리 | 미착수 |
| 2 | [GitLab 연구진행·보고](agents/2-gitlab) | 업무 진행률, KPI, 주간보고 | 미착수 |
| 3 | [세미나 Knowledge](agents/3-seminar) | 세미나 내용·자료 축적, 자연어 검색 | 미착수 |
| 4 | [학회·연구 일정](agents/4-schedule) | 학회·논문·과제 Deadline, 발표, 연차 | **동작 중** |
| 5 | [코드·인수인계](agents/5-code-kt) | 코드 분석·검색, 인수인계 | 미착수 |

## 공유 계층 (`shared/`)

에이전트끼리 주고받는 것만 여기 둔다. 각자의 내부 데이터는 자기 폴더에 둔다.

| 파일 | 무엇 | 쓰는 쪽 | 읽는 쪽 |
|---|---|---|---|
| `members.yaml` | **연구실 명단 — 유일한 원본** | 사람이 직접 | 전부 |
| `lab.db` | 공유 DB (SQLite) | 각 에이전트가 자기 행만 | 전부 |

명단을 각 에이전트가 따로 들고 있으면 반드시 어긋난다. 사람이 나가고 들어오는 건
`shared/members.yaml` 한 곳에서만 고친다. 자세한 규약은 [shared/README.md](shared/README.md).

## 시작하기

```bash
pip install pyyaml pdfplumber
cd agents/4-schedule && python watch.py month
```

각 에이전트 폴더의 `README.md` 와 `CLAUDE.md` 를 먼저 읽을 것.
`CLAUDE.md` 에는 그 에이전트에서 Claude가 지켜야 할 규칙이 들어 있다.

## 설계 원칙

**해석은 LLM이, 계산은 코드가.** 웹페이지·PDF·자연어를 읽어 의미를 파악하는 일은 에이전트가 하고,
날짜 계산·상태 비교·집계처럼 틀리면 안 되는 일은 파이썬이 결정적으로 처리한다.
4번 에이전트가 이 구조로 만들어져 있으니 참고할 것.

**모르면 비워둔다.** 확인되지 않은 값을 그럴듯하게 채우지 않는다.
없는 마감일을 만들어내는 것이 일정 에이전트의 최악의 실패다.

**규칙은 문서가 아니라 코드로 막는다.** 경고만 띄우면 그냥 지나간다.
4번 에이전트의 `upsert-sessions` 가 명단 밖 제1저자를 거부하는 것이 그 예다.
