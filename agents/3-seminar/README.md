# 세미나 Knowledge Agent

> **상태: 미착수** — 담당자가 정해지면 여기부터 채우세요.

## 역할

발표자료 저장·요약, 키워드 추출, Q&A 정리, 자연어 기반 과거 세미나 검색

## 주요 기능

- 발표내용 자동 요약, 연구 키워드 추출
- 분야별 세미나 분류
- "작년에 수전해 세미나 뭐 있었어?" 같은 자연어 검색

## 주요 기술

LLM · RAG · Embedding · Vector DB · PDF parsing

## 공유 계층과의 관계

세미나 **일정**은 4번이 `shared/lab.db` 에 `kind='seminar'` 로 넣는다 — 읽어서 쓸 것.
발표 **내용**은 이 에이전트가 소유하며, 필요하면 `seminars` 테이블을 새로 만든다.

규약 전문: [../../shared/README.md](../../shared/README.md)

## 시작할 때

1. 이 README 를 채운다 (담당자, 데이터 출처, 산출물).
2. `CLAUDE.md` 를 만들어 이 에이전트에서 Claude가 지킬 규칙을 적는다.
3. 다른 에이전트가 볼 결과가 있으면 `shared/lab.db` 에 **자기 `agent` 행만** 쓴다.

동작하는 예시는 [4번 에이전트](../4-schedule)를 참고할 것 —
LLM이 해석하고 파이썬이 계산하는 구조로 되어 있다.
