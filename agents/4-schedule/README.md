# 랩 연구·학회 일정 에이전트

"언제 무엇을 해야 하는지"를 관리한다. 내가 지정한 학회만 감시해서 마감을 추적하고,
프로그램북에서 우리 랩 사람들 발표를 찾아내고, 논문·과제·세미나까지 합쳐
캘린더로 보여주고 각자 폰에 알림이 가게 한다.

## 역할 분담

| | 담당 |
|---|---|
| 사이트·PDF 읽고 일정 해석 | 에이전트(LLM) — 사이트 구조가 바뀌어도 대응 |
| 상태 저장 · 변경 감지 · 캘린더 · 리포트 | `watch.py` — 결정적으로 동작 |

크롤러를 하드코딩하지 않은 이유: 학회 사이트는 구조가 제각각이고 매년 바뀐다.

## 두 종류의 일정

**학회 일정**은 에이전트가 사이트에서 긁어온다 → `targets.yaml`에 학회만 등록.
**그 밖의 일정**(논문 Revision, 과제 보고서, 세미나)은 웹에 없으니 직접 적는다 → `personal.yaml`.

둘은 리포트·캘린더·대시보드에서 하나의 타임라인으로 합쳐진다.

## 처음 할 일

1. `members.yaml` 에 연구실 명단. **`aliases`가 핵심이다** — 국내 학회는 한글,
   국제 학회는 영문으로 실리므로 나올 수 있는 표기를 모두 적어야 프로그램에서 찾아낸다.
2. `targets.yaml` 확인. 현재 한국화학공학회 · NAT · ICCAS 세 곳이 등록되어 있다.
3. `personal.yaml` 의 예시 항목을 실제 일정으로 교체.

## 수집 · 갱신

```
/conf-check
```
등록된 학회를 돌며 초록·등록 마감을 수집한다. 새로 뜬 마감과 **날짜가 바뀐 마감**을 알려준다.

```
/conf-program 프로그램북.pdf
```
프로그램북에서 우리 랩 사람들 발표를 찾아 일시·장소까지 정리한다.
URL을 줘도 되고, 인자 없이 부르면 에이전트가 학회 사이트에서 찾는다.

## 알림 받기 — 구글 캘린더 연결

`python watch.py ics` 가 만드는 파일을 캘린더에 넣으면 끝이다.

- `calendars/all.ics` — 랩 전체
- `calendars/홍길동.ics` — 그 사람 발표 + 공통 마감 + 랩 공통 연구 일정

**구글 캘린더에 넣는 방법** (권장)

1. [calendar.google.com](https://calendar.google.com) → 우측 상단 **설정(⚙)** → **가져오기/내보내기**
2. **가져오기**에서 `.ics` 파일 선택, 넣을 캘린더 지정 → 가져오기

일정마다 고정 ID를 붙여두었으므로, 나중에 갱신된 파일을 **다시 가져와도 중복이 생기지 않고
기존 일정이 업데이트된다.** 새 학회를 추가해도 기존 일정의 ID는 바뀌지 않는다.

알림 시점은 캘린더 앱이 처리한다.

| | 알림 |
|---|---|
| 마감 (초록·등록·최종본) | 7일 전, 1일 전 |
| 학회 발표 | 1일 전, 1시간 전 |
| 세미나·미팅 | 1시간 전 |
| 그 외 연구 일정 | 3일 전, 1일 전 |

별도 앱을 깔 필요가 없고 기기·OS를 안 가린다.

**URL 구독 방식은 권장하지 않는다.** 구글이 주기적으로 자동 갱신해주지만 `.ics`를 누구나
접근 가능한 공개 URL에 올려야 하고, 그러면 미발표 연구 제목과 랩 일정이 외부에 노출된다.
자동 갱신이 꼭 필요하면 Google Calendar API 연동(OAuth 설정 필요)이 더 안전하다.

## 대시보드

`dashboard.html` 은 발표·마감·연구 일정을 한 화면에서 보는 일정판이다.
사람별 필터가 있어서 "내 것만" 볼 수 있다. Artifact로 퍼블리시하면
랩 사람들이 링크만으로 폰에서 열어본다.

```bash
python watch.py sync    # data.json 을 dashboard.html 에 주입
```
그 다음 같은 파일 경로로 Artifact를 다시 퍼블리시하면 URL이 유지된 채 반영된다.

## 파일

- `targets.yaml` — **감시할 학회 목록**
- `members.yaml` — **연구실 명단 (aliases 중요)**
- `personal.yaml` — **논문 · 과제 · 세미나 일정 (직접 관리)**
- `CLAUDE.md` — 에이전트 행동 규칙
- `dashboard.html` — 캘린더 대시보드
- `state.json` — 수집된 학회 일정 누적
- `LATEST.md`, `reports/` — 리포트
- `calendars/` — 개인별 .ics
- `scans/` — 프로그램북에서 뽑아낸 페이지
- `watch.py` — 상태/캘린더/리포트 유틸

## 명령

```bash
python watch.py month           # 이번 달 주요 일정
python watch.py month 2026-10   # 특정 달
python watch.py report          # 전체 리포트 → LATEST.md
python watch.py ics             # 캘린더 생성
python watch.py sync            # 대시보드 데이터 주입
python watch.py list            # 감시 대상 + 명단
python watch.py show            # 저장된 일정 전체
python watch.py reset           # 수집 데이터 비우기 (설정은 유지)
```

## 한계

- 로그인이 필요한 회원 전용 공지는 읽지 못한다.
- 스캔 이미지 PDF는 텍스트가 없어 OCR 없이는 못 읽는다. 이 경우 추측하지 않고 알린다.
- 등록 **제출·결제**는 하지 않는다. 로그인·결제·본인인증이 걸려 있고,
  잘못 제출하면 되돌릴 수 없다. 마감 감시와 알림, 그리고 등록 폼 대신 채워두기까지가 범위다.
